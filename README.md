# AI-WhatsApp-Lead-Qualifier
🚀 WhatsApp AI Lead Orchestrator
Overview: An automated pipeline that intercepts WhatsApp business queries, analyzes intent using LLMs, and categorizes data into a structured CRM.

The Tech Stack:

Twilio API: WhatsApp Gateway.

Google Gemini Pro: Natural Language Processing & JSON Extraction.

Make.com: Workflow Orchestration.

Google Sheets: Cloud Database/CRM.

Core Engineering Features:

Unstructured to Structured Data: Converts conversational text into JSON schemas.

Complexity Scoring: AI-driven project estimation (1-10 scale).

Automated Response Loop: Immediate customer engagement via Twilio.
